# BC Book Studio

Aplikasi mandiri untuk alur editorial dan penerbitan buku BahasaCerdas.

## Jalankan

Node.js 22+: `npm install`, lalu `npm run dev`.

## Status

MVP editor: membuat buku kelas 1–12/referensi, menambah bab, review, persetujuan demonstrasi, dan ekspor HTML siap cetak. Data sementara di localStorage browser. **Belum siap produksi**: autentikasi, database, AI agents, PDF/EPUB, CI/CD, dan VPS belum diimplementasikan. Persetujuan saat ini bukan otorisasi penerbit yang aman.
