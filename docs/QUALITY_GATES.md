# Gerbang Mutu Buku

Angka target berikut adalah target rancangan dan harus dikalibrasi melalui validasi ahli serta uji coba, bukan klaim hasil sistem.

| Dimensi | Target rancangan | Gerbang |
|---|---:|---|
| Akurasi isi | ≥95/100 | Tidak ada kesalahan kritis |
| Ketepatan bahasa | ≥95/100 | Tidak ada kesalahan bahasa kritis |
| Kelayakan pedagogis | ≥90/100 | Tidak ada risiko ketidaksesuaian jenjang |
| Keselarasan kurikulum | ≥95/100 | Semua klaim pemetaan memiliki sumber |
| Kesiapan tata letak | ≥90/100 | Tidak ada teks terpotong/aset hilang |
| Dukungan sumber | 100% klaim yang wajib dirujuk | Semua rujukan dapat ditelusuri |

## Klasifikasi temuan
- Critical: memblokir proses.
- High: harus diperbaiki sebelum persetujuan editor.
- Medium: perlu keputusan editor atau perbaikan terencana.
- Low: penyempurnaan.

## Persetujuan
Skor otomatis hanya alat bantu. Editor manusia memeriksa bukti, menyelesaikan temuan, dan menyetujui penerbitan. ISBN hanya dicantumkan jika benar-benar telah diperoleh secara resmi.
