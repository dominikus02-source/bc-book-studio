# Batas Tahap Frontend dan Agen

## Termasuk dalam tahap sekarang
- Kerangka aplikasi web dan sistem desain.
- Navigasi dan halaman dasbor.
- Katalog peran agen dan spesialisasi.
- Kontrak profil kelas 1–12.
- Rancangan tampilan modul produksi.
- Status kesiapan yang jujur dan tidak menampilkan data palsu.

## Ditunda ke tahap backend
- Autentikasi dan otorisasi nyata.
- Penyimpanan proyek, naskah, aset, dan versi.
- Eksekusi agen dan orkestrasi.
- Antrean, pekerja, penjadwalan, checkpoint, dan pemulihan.
- Integrasi penyedia model dan pencatatan biaya.
- Penyimpanan berkas dan ekspor PDF/EPUB.
- Integrasi API BahasaCerdas.

## Kriteria sebelum frontend dianggap siap
1. Build produksi berhasil pada lingkungan bersih.
2. TypeScript dan lint lulus.
3. Navigasi seluruh modul dapat digunakan.
4. Tampilan diuji pada lebar ponsel, tablet, dan desktop.
5. Status layanan belum aktif terlihat jelas.
6. Tidak ada rahasia atau kredensial pada kode sisi klien.
7. Tidak ada data proyek contoh yang disajikan sebagai data produksi.
