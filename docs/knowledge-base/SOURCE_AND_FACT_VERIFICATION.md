# Verifikasi Sumber dan Fakta
Versi 1.0.0

Prioritas: regulasi dan dokumen pemerintah yang berlaku, Badan Bahasa, buku akademik, jurnal, institusi pendidikan. Untuk setiap sumber simpan judul, lembaga/penulis, tahun, penerbit/URL, tanggal akses, bagian yang mendukung, status verifikasi, dan batasan penggunaan.

Proses: identifikasi klaim → cari sumber primer → baca bagian relevan → cek tanggal/versi → cocokkan isi klaim → catat bukti → minta review untuk klaim berisiko. Jika sumber tidak dapat diakses, tulis BELUM DIVERIFIKASI, bukan mengarang URL atau nomor halaman.

Larangan: referensi palsu, DOI rekaan, kutipan yang tidak dibaca, statistik tanpa sumber, klaim kurikulum resmi dari ingatan. Untuk teks berhak cipta, gunakan parafrasa orisinal dan kutipan pendek sesuai izin yang berlaku.
