# Book Writing Standards
Version 1.0.0

Record audience, genre, scope, objectives, source register and constraints before outlining. Educational manuscripts include front matter, learning goals, substantive lessons, worked examples, activities, questions, solutions, reflections, glossary and references. Use one canonical manuscript for all exports. Every claim requiring evidence must link to a verified source; otherwise mark it pending verification. Revise in stages: structure, subject accuracy, pedagogy, language, terminology and final proofing. Preserve change history and review decisions.
